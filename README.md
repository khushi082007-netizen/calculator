# Calculator

A modern, responsive calculator UI built with plain HTML, CSS and JavaScript.

This project is a lightweight calculator web app with a polished UI, accessible markup, and event-driven JavaScript. It's intended as a small frontend demo you can open locally or publish to GitHub Pages.

**Features**
- Clean, responsive UI with a button grid and visual states
- Accessible markup (ARIA labels, semantic layout)
- Event-delegation based JavaScript (no inline handlers)
- Basic numeric and operator support, decimal handling, delete/clear

**Files**
- `index.html` — main markup and button grid
- `style.css` — modern responsive styles and layout
- `script.js` — calculator behavior and event handling

Usage
-----

Open the app in your browser by double-clicking `index.html`
